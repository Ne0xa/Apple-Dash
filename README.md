# 🍎 Apple Dash

Apple Dash is a platformer inspired by **Geometry Dash**, in which you play as an apple. It is built for the **Devtober side quests** (one theme per day for 31 days) as a school project.

## 🎮 About

Each day of Devtober comes with a theme. For each one, I add a mechanic, an obstacle or a gameplay element to Apple Dash. The game grows theme after theme, from the simple apple of day 1 to the victory screen of day 15 and beyond.

---

## ✨ Features

- 🍎 A playable apple character (day 1)
- 🏺 Relics that grant buffs (day 2)
- 🔬 A temporary shrinking effect (day 3)
- 🌵 Cacti that turn invisible (day 4)
- 👋 A hand that slaps the player and sends them flying to the side they were hit from (day 5)
- 👹 An ogre that appears and chases the player (day 6)

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/Ne0xa/Apple-Dash.git

# Go to the project folder
cd Apple-Dash
```

1. Install [Unity Hub](https://unity.com/download) and the Unity version used by the project (6000.3.23f1).
2. In Unity Hub, click **Add** and select the `Apple-Dash` folder.
3. Open the project, then open the UIScene.
4. Click **Play** to start the game.

## 🕹️ How to play

Just like in Geometry Dash, the apple **moves forward on its own**. Your only job is to **jump at the right moment** to avoid obstacles and traps.

- **Goal**: reach the end of the level without dying.
- **Controls**: press **Space** to jump
- **Tip**: watch the obstacles closely, since some of them change behavior (cactus that vanish, platforms that run away, an ogre that chases you...).
